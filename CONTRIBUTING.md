# Contributing

Thanks for contributing to kage.

## Development

Requirements: Node.js 18+ and git.

```bash
npm ci
npm run lint
npm test
```

Please keep changes focused, add or update a regression test for behavior changes, and do not commit generated `bin/` or `dist/` output.

## Pull requests

- Explain the user-facing problem and the chosen fix.
- Include relevant platform details for CLI or filesystem changes.
- Ensure CI passes before requesting review.

By contributing, you agree that your work is provided under this repository's [MIT license](./LICENSE).
